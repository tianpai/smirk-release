Imagine there exists an oracle that reads one's mind and produces the
best-fitting resume given an arbitrary job description.

This experimental project is an attempt to achieve some or most of that. I hope
this desktop app can do better than a new grad who has little clue about resume
writing. It does not need to beat the professional writers who charge as much
as, if not more than, a therapy session.

The project is taking shape but still very early in development. Anything can
change unannounced. I built this to help myself first, and I actually use it,
unlike many projects that even their creators abandon.

Unlike code, the quality of the generation is hard to test. Even for coding,
a human has to be in the loop. If the goal were just to produce a resume of any
quality, this project would already be done, as many others are. However, to
generate a sound and accurate resume that demands very little attention and
only necessary user input is by nature a much more difficult problem. That is
why the app has no PDF uploads and no chat to interact with. It functions like
an oracle: create the "mind", which is an inventory of everything you achieved
and want to highlight, then give it some job descriptions, and the app creates
the resumes.

For anyone who is curious, the release is available on the "Releases" page,
free to use. Only the latest 3 releases are kept. Download the correct format,
exe or dmg, according to the operating system. The Windows build is unsigned so
SmartScreen will warn. Bring your own API key and create a profile and
inventory before generating. No data is or will be collected and all data is
kept local.

Source code remains private. I welcome all ideas, feedback and complaints.
Just submit an issue on this page.
